# Offline provider marks

These SVGs are source assets for the optional provider/model playing pieces.
`sources.json` pins each upstream URL and SHA-256. Lobe Icons sources use its MIT
license (`LICENSE.md`); the Xiaomi SVG uses Simple Icons' CC0 dedication
(`SIMPLE-ICONS-LICENSE.md`). Preserve these notices when redistributing.

`provider-pieces.js` embeds the paths into coloured cream badges; `art.js` embeds
their symbols into the standalone game. No external image requests are needed.
The names and marks identify models/controllers; they do not imply endorsement.
Copyright licenses do not grant trademark rights.
